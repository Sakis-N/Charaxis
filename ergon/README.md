# Ergon: διαχείριση πελατών, εγκαταστάσεων & εργασιών

Προσωπική εφαρμογή για μηχανικούς και τεχνικούς. Τρέχει στον υπολογιστή ή στο NAS σου και τα δεδομένα μένουν σε έναν φάκελο (`data/`): βάση SQLite + φωτογραφίες και αρχεία.

## Λειτουργίες

**Οργάνωση**
- Πελάτες → εγκαταστάσεις → εργασίες, με πλήρες ιστορικό ανά πελάτη και ανά εγκατάσταση
- Έργα που ομαδοποιούν πολλές εργασίες, με πρόοδο, αξία, κόστος και κέρδος
- Εξοπλισμός ανά εγκατάσταση: μάρκα, μοντέλο, σειριακός, εγγύηση, με ειδοποίηση πριν λήξει η εγγύηση
- Τεχνικές σημειώσεις ανά εγκατάσταση και ανά εργασία (εσωτερικές και για τον πελάτη)
- Φωτογραφίες και αρχεία ανά εργασία, εγκατάσταση και πελάτη, με όριο 50MB ανά εγκατάσταση. Από το κινητό τραβάς φωτογραφία κατευθείαν.
- Γενική αναζήτηση: όνομα, τηλέφωνο, ΑΦΜ, διεύθυνση, σειριακός αριθμός, σημειώσεις

**Πρόγραμμα**
- Ημερολόγιο σε προβολή μήνα, εβδομάδας ή ημέρας, με χρώμα ανά τεχνικό ή συνεργείο. Σέρνεις μια εργασία σε άλλη μέρα για να αλλάξει ημερομηνία.
- Ανάθεση εργασιών σε τεχνικούς και συνεργεία, με φίλτρα ανά τεχνικό
- Χάρτης με όλες τις εγκαταστάσεις και τα ραντεβού. Η διαδρομή της ημέρας ανοίγει με ένα κλικ στο Google Maps.
- Συμβόλαια συντήρησης: ορίζεις «κάθε Χ μήνες» και οι εργασίες δημιουργούνται μόνες τους 45 ημέρες πριν
- Υπενθυμίσεις, εκπρόθεσμες εργασίες, εργασίες χωρίς ημερομηνία, λήξεις εγγυήσεων

**Πεδίο**
- Ηλεκτρονική υπογραφή πελάτη (δάχτυλο ή ποντίκι) σε εργασίες και προσφορές
- Δελτίο εργασίας για εκτύπωση ή PDF, με υλικά, φωτογραφίες και υπογραφή
- Υλικά από αποθήκη: το απόθεμα αφαιρείται αυτόματα και φαίνεται το κέρδος ανά υλικό
- Λειτουργεί ως εφαρμογή στο κινητό («Προσθήκη στην αρχική οθόνη»)

**Οικονομικά**
- Προσφορές με είδη, ΦΠΑ, έκπτωση και όρους. Εκτυπώνονται σε PDF, υπογράφονται και με ένα κλικ γίνονται εργασία.
- Πληρωμές, υπόλοιπα ανά πελάτη, έξοδα ανά κατηγορία
- Αναφορές: τζίρος, εισπράξεις, κέρδος ανά μήνα, τεχνικό, είδος εργασίας και πελάτη
- Εξαγωγή σε CSV (ανοίγει στο Excel) και backup της βάσης

**Κινητό**
- Αναγνώριση πελάτη στην εισερχόμενη κλήση: στο Android, το MacroDroid ή το Tasker καλεί το `/api/lookup` και δείχνει ειδοποίηση με όνομα, εγκατάσταση, επόμενο ραντεβού και υπόλοιπο. Οδηγίες στις Ρυθμίσεις.
- Συγχρονισμός επαφών: οι πελάτες εξάγονται ως `.vcf` για τις επαφές του κινητού
- Τα ραντεβού εμφανίζονται στο Google ή Apple Calendar με συνδρομή σε σύνδεσμο `.ics`

## Γρήγορη εκκίνηση (υπολογιστής)

Χρειάζεται Node.js 20 ή νεότερο.

```bash
cd ergon
cp .env.example .env        # άλλαξε APP_PASSWORD, SESSION_SECRET, API_TOKEN
npm install
npm run seed                # προαιρετικό: δοκιμαστικά δεδομένα
npm run build && npm start  # http://localhost:3100
```

Για ανάπτυξη: `npm run dev`.

## Στο NAS με Docker (Synology / QNAP / Unraid / Raspberry Pi)

1. Αντέγραψε τον φάκελο `ergon/` στο NAS, π.χ. `/volume1/docker/ergon`.
2. Φτιάξε το `.env` από το `.env.example`.
3. Τρέξε:
   ```bash
   docker compose up -d --build
   ```
   Στο Synology γίνεται και από το Container Manager → Project → «Create» με αυτόν τον φάκελο.
4. Άνοιξε `http://IP-του-NAS:3100`.

Τα δεδομένα μένουν στο `ergon/data/`. Πάρε backup αυτού του φακέλου, π.χ. με Hyper Backup.

Δοκιμαστικά δεδομένα μέσα στο container: `docker exec ergon node scripts/seed.mjs`.

### Πρόσβαση από έξω (κινητό στο πεδίο)
Μην ανοίξεις την πόρτα 3100 κατευθείαν στο internet. Προτιμώνται:
- **Tailscale** (το πιο απλό): εγκαθίσταται στο NAS και στο κινητό, και η εφαρμογή ανοίγει από παντού σαν να είσαι στο σπίτι.
- ή reverse proxy με HTTPS, π.χ. Synology DSM → Login Portal → Reverse Proxy, με πιστοποιητικό Let's Encrypt.

Αν η εφαρμογή ανοίγει από άλλη διεύθυνση από αυτή που βλέπει ο server, όρισε `PUBLIC_URL` στο `.env` (π.χ. `https://ergon.example.com`), ώστε οι σύνδεσμοι για το κινητό να είναι σωστοί.

## Ρυθμίσεις `.env`

| Μεταβλητή | Τι κάνει |
|---|---|
| `APP_PASSWORD` | Κωδικός εισόδου |
| `SESSION_SECRET` | Τυχαίο μακρύ κείμενο για την υπογραφή της σύνδεσης |
| `API_TOKEN` | Κλειδί για τα endpoints του κινητού (κλήσεις, επαφές, ημερολόγιο). Κενό σημαίνει ότι είναι κλειστά. |
| `DATA_DIR` | Πού αποθηκεύονται βάση και αρχεία (default `./data`) |
| `PUBLIC_URL` | Προαιρετικό: η εξωτερική διεύθυνση της εφαρμογής |
| `TZ` | Ζώνη ώρας (default `Europe/Athens`) |
